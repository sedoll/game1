# Circuit Breaker (써킷 브레이커)

Phaser 3로 제작한 2D 탑뷰 디펜스 + 간단한 크래프팅 프로토타입입니다.

## 콘셉트
- 플레이어는 메인보드 내부의 마이크로 엔지니어입니다.
- 중앙 코어로 몰려오는 바이러스 몬스터를 막아야 합니다.
- 빌드 페이즈에서 파워 소스, 와이어, 터렛을 설치/회수하며 회로를 구성합니다.
- 터렛은 파워 소스에서 와이어로 연결되어 전력이 전달되어야만 작동합니다.

## 조작
- 이동: `WASD` 또는 방향키
- 설치 타입 선택: `1`(파워 소스), `2`(와이어), `3`(터렛)
- 설치/회수: **마우스 좌클릭** (또는 `E`로 플레이어가 서 있는 칸)
- 웨이브 시작: `Space`

## 설치(배치)가 안 될 때 체크
- 설치/회수는 **웨이브 진행 중에는 비활성화**되고, 웨이브 사이의 빌드 페이즈에서만 동작합니다.
- 중앙 코어 칸에는 설치할 수 없습니다.
- 재료(`wire`, `resistor`, `board`)가 부족하면 설치되지 않습니다.

## 실행
정적 파일 서버로 프로젝트 루트를 서빙하면 됩니다.

예시:
```bash
python3 -m http.server 8000
```
브라우저에서 `http://localhost:8000` 접속.
